// TECH_EVALUATION: SECTION_07 // CRITICAL TRADE-OFFS
EVALUASI KRITIS ENGINE

Claude Pro Desktop vs Pure Cloud M365

Menjawab Pertanyaan: "Kenapa kita tidak memakai akun Claude Pro standalone saja di laptop staf untuk tembak briefing ke Teams?" — Berikut catatan kerugian dan risiko operasionalnya.

Parameter Operasional Opsi A: Claude Pro Desktop (Standalone / MCP Lokal) Opsi B: Pure Cloud Flow (Power Automate + Claude API) ⭐ REKOMENDASI
Reliability & Standby 24/7 BERISIKO TINGGI
Bergantung 100% pada laptop staf yang menyala. Jika laptop mati, sleep, atau dibawa pulang, sistem otomatis berhenti. 		100% SERVERLESS CLOUD
Berjalan 24/7 di cloud Microsoft Azure/M365 tanpa bergantung pada laptop fisik siapapun di kantor.
Morning Brief 07.45 WIB TIDAK BISA JALAN
Harus ada staf yang sudah membuka laptop dan menyalakan Claude sebelum jam 07.45 pagi. Sangat tidak realistis. 		OTOMATIS TEPAT WAKTU
Cloud scheduler Power Automate otomatis mengeksekusi jam 07.45 WIB setiap hari kerja secara presisi.
Koneksi ke Microsoft Teams KOMPLEKS & TIDAK NATIVE
Claude Desktop tidak punya konektor native ke Teams organisasi. Membutuhkan script Python/webhook lokal yang rentan error. 		NATIVE M365 CONNECTOR
Menggunakan Microsoft Teams Actionable Card resmi bawaan M365 dengan otentikasi Single Sign-On (SSO).
Keamanan & Kredensial RISIKO KEBOCORAN KUNCI
Token kredensial disimpan di file lokal laptop pengguna. Bahaya jika laptop hilang atau terkena malware. 		MICROSOFT ENTRA ID
Kredensial disimpan aman di Microsoft Azure Key Vault dengan audit trail berstandar perbankan.
Biaya Operasional (OpEx) Flat $20 / bulan (~Rp 320.000)
Hanya bisa dipakai oleh 1 pengguna (Pak Melvin) di komputernya sendiri. 		Pay-Per-Use Token (~Rp 75.000 - Rp 150.000 / bln)
Sangat murah untuk seluruh 9 karyawan karena hanya membayar token teks yang benar-benar dipakai.
KESIMPULAN FLEEK: Gunakan Pure Cloud Flow (Power Automate + Claude API) untuk mesin otomatisasi harian perusahaan. Akun Claude Pro tetap ideal dipegang Pak Melvin untuk riset ad-hoc & tinjau tender tebal (RKS).
